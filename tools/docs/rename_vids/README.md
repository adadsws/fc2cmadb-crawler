# 重命名视频

[中文](README.md) | [English](README_EN.md)

根据视频总比特率和帧高度，批量重命名视频及所在目录。

## 功能

- 默认视频名格式为 `原名 [023Mbps_2048p].mp4`；所在目录名追加相同形式的标签。
- 执行前显示预览，确认后才改名。
- 可按最近批次撤销多次重命名；遇到重名时，现有目标会归档以便恢复。

## 1. 准备环境

需要 Windows PowerShell 和 `ffprobe.exe`。按 [FFprobe 安装说明](../../rename_vids/reference/tools/ffmpeg.md) 将 `ffprobe.exe` 放入 `tools/rename_vids/`，或将它加入系统 `PATH`。

## 2. 安装工具

此工具随 [主项目](../../../README.md) 提供。下载或克隆项目并完成上面的 FFprobe 配置后即可使用；不需要安装 Python 包。

## 3. 使用工具

双击 `tools/rename_videos_by_media_info.bat`，选择 `1`，输入视频文件夹路径。预览按目录分组，先列目录改名，再列该目录下所有待改文件；确认后才执行。重命名模式会保持，可继续输入下一个文件夹。

在主菜单选择 `2`，工具会按最近处理顺序列出可撤销的文件夹。输入编号选一批，查看按目录及所属文件排列的还原预览并确认；完成后可继续选择下一批。数字菜单回车默认选择 `1`；`b` 返回主菜单，`q` 退出。
