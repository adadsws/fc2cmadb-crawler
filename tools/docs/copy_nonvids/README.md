# 复制非视频文件

[中文](README.md) | [English](README_EN.md)

把一个文件夹中的非视频文件复制到新位置，并保留原有目录结构。源文件夹不会改变。

## 功能

- 只跳过视频；图片、文档等其他文件会复制。
- 目标可选项目 `~outputs/`、源文件夹旁的 `<源文件夹名>_nonvids`，或手动指定位置。
- 目标已存在时会提示确认；同名文件可能被覆盖。

## 1. 准备环境

安装 Python 3，在终端运行 `python --version` 确认命令可用。此工具不需要安装爬虫依赖。

## 2. 安装工具

此工具随 [主项目](../../../README.md) 提供。下载或克隆项目后，在项目根目录打开终端；无需额外安装 Python 包。

## 3. 使用工具

运行 `python -m tools.copy_nonvids`，或双击 `tools/run_copy_nonvids.bat`。输入源文件夹，再选择目标位置。也可直接运行：

```powershell
python -m tools.copy_nonvids "源文件夹" "目标文件夹"
```

目标菜单中，`1` 复制到源目录旁的 `<源文件夹名>_nonvids`，`2` 复制到项目默认输出路径，`3` 手动输入目标路径。回车默认选择 `1`；路径必须明确输入。处理完一个文件夹后可继续输入下一个，`b` 返回主菜单，`q` 退出。默认项目输出在 `~outputs/`。
