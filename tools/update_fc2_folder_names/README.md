# 更新 FC2 文件夹名称

[中文](README.md) | [English](README_EN.md)

按 `fc2cmadb.com` 的最新販売者名称更新现有 FC2 作品文件夹名称。

## 功能

- 递归查找名称含 `fc2-ppv-<数字>` 的文件夹；先统计販売者名称出现次数，优先处理有效缓存，再优先查询出现次数多的未缓存名称。同一名称每批只查询一次，30 天内命中本项目保存的当前名或旧名时免查询。搜索须返回名称精确匹配的販売者；原名称还须与其当前名或旧名匹配。
- 启动或复用主程序的可见 Chrome，并与主程序一样确认站点登录状态；确认完成后才进入菜单或扫描目录。
- 保留原名称中制作人前的所有文字和原有影片标题；名称过长时按主程序规则截断。文件夹内的文件不变。
- 修改前预览；遇到目标重名或无法确认名称边界时跳过；可撤销最近的多批修改。
- 每次启动本工具后，影片详情及搜索访问合计达到 50 次会提示一次，程序继续运行，下次启动重新计数。販売者名称缓存保存在项目 `~outputs/`。实际访问搜索网址默认至少间隔 12 秒；缓存命中不访问站点。首次收到 429 时立即停止后续获取，展示已准备好的部分结果；可选择只改这部分，未准备好的目录跳过。

## 1. 准备环境

安装 Python 3 和 Google Chrome，并确认可访问 `fc2cmadb.com`。在终端运行 `python --version` 检查环境。首次运行可能需要在 Chrome 中完成站点验证或登录。

## 2. 安装工具

此工具随 [主项目](../../README.md) 提供。下载或克隆项目后，在项目根目录安装此工具需要的包：

```powershell
python -m pip install selenium==4.36.0 beautifulsoup4==4.11.1 requests
```

## 3. 使用工具

运行 `python -m tools.update_fc2_folder_names`，或双击 `tools/run_update_fc2_folder_names.bat`。工具会先准备 Chrome 并确认登录状态；未登录时按提示在该 Chrome 中登录，确认后才显示菜单或扫描根目录。选择更新后输入要扫描的根目录，查看预览并确认。可先只预览：

```powershell
python -m tools.update_fc2_folder_names "根目录" --dry-run
```

批量访问可指定搜索网址最短间隔（2–32 秒，默认 12 秒），例如在 BAT 后传入参数：

```powershell
tools/run_update_fc2_folder_names.bat "根目录" --dry-run --interval 12
```

预览先显示待重命名和跳过数量，跳过项不逐条列出。长度截断与制作人名称更新按待改目录计数，制作人变动按旧名到新名汇总；只有“其他原因”默认逐条显示原名和目标名。同一目录可能同时计入前两项。确认菜单选 `2` 可展开本批全部待重命名目录，查看后返回确认菜单；选 `1` 才执行改名。主菜单选 `2` 可按最近处理顺序查看可撤销的文件夹；输入编号选一批，确认该批还原预览后可继续选择。完成后可继续输入下一个根目录；数字菜单回车默认选择 `1`，`b` 返回主菜单，`q` 退出。

若目录名中的英文双引号与磁盘上的弯引号不同，工具会在唯一匹配时提示实际目录路径，复制提示的路径重新输入即可。

只需撤销时可运行 `python -m tools.update_fc2_folder_names --undo`，无需启动 Chrome。
