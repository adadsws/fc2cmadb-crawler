# FC2 目录更新限流等待与重试

## 目标

- 批量读取作品页时主动控制访问间隔。
- 收到 429 后等待并重试当前番号；重试仍失败时停止整批，不用部分扫描结果改名。
- 重试相同 URL 必须产生新的页面请求，避免读取 Chrome 中残留的 429 页面。
