# 所有变更预览突出源与目标差异

## 目标

- 在视频重命名工具的 CMD 预览中，对源路径中将替换的片段和目标路径中新生成的片段使用不同颜色。
- 未变化的路径保持默认颜色；目标已存在的归档警示仍清晰可见。
- 预览展示不修改文件；确认、返回和退出仍按原流程执行。
- 快捷方式工具的旧 URL 与新 URL、复制工具的源目录与目标目录、重命名工具的撤销预览使用同一配色。
- 主爬虫没有源与目标对照预览，不新增此类交互。

## 验收场景

| 场景 | 预期 |
|---|---|
| 首次添加媒体标签 | 新增标签在目标侧着色，共同的路径和扩展名不着色 |
| 替换已有媒体标签 | 源侧旧差异与目标侧新差异分别着色 |
| 目标已存在 | 归档提示保留醒目颜色，预览仍显示名称差异 |
| 预览输入 `b` | 返回主菜单，不重命名样本 |
| 快捷方式域名修复预览 | 旧域名部分为红色，新域名部分为绿色 |
| 复制目录对照 | 只强调源目录与目标目录中不同的字符 |
| 输出重定向到文件 | 不写入 ANSI 颜色控制符 |

## 验证记录

- 真实 BAT 入口在 PTY 中运行首次添加标签与替换旧标签两个预览；终端输出分别包含目标侧绿色控制序列、源侧红色及目标侧绿色控制序列。
- 已有目标的预览仍显示黄色归档警示。
- 两次都在预览输入 `b`、主菜单输入 `q`，退出码为 0；隔离样本文件名未改变。
- 快捷方式工具实际入口显示旧域名红色、新域名绿色；复制工具实际入口显示目标目录新增后缀绿色，均在确认前返回。
- 重命名工具撤销预览实际入口显示待移除标签红色；使用隔离的 `LOCALAPPDATA` 撤销记录，输入 `b` 返回，样本文件及撤销记录未改变。
- 快捷方式工具重定向输出文件未包含 ANSI 控制字符；`python -m unittest discover -s tests` 共 48 项通过，编译与 `git diff --check` 通过。
