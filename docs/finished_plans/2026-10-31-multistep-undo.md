# 原地修改工具支持多步撤销

## 范围

- 视频媒体信息重命名、FC2 作品目录更新、快捷方式域名修复三种原地修改流程都记录每次已确认的修改，并可按最近批次向前撤销多步。
- 非视频复制只写目标副本，不改源目录；主爬虫主要新建目录，不纳入本次撤销菜单。
- 记录放在本机非 Git 输出或已有本地应用数据目录；不得向终端输出 `.url` 原文中的敏感参数。
- `b` 返回主菜单、`q` 退出；数字菜单回车仍默认首项；撤销预览显示原名和恢复目标的彩色差异。

## 验收场景

| 输入或状态 | 预期 |
|---|---|
| 连续执行两批目录改名，再撤销 2 步 | 按最近批次顺序恢复两批原名 |
| 连续执行两批快捷方式域名修改，再撤销 2 步 | 原始字节与编码均恢复 |
| 视频重命名连续两批，再撤销 2 步 | 两批均可分别预览并恢复；旧 `last-operation.json` 不被覆盖 |
| 撤销前目录目标名或快捷方式内容被外部改动 | 停止该批撤销，不覆盖外部改动 |
| 重启工具后撤销 | 仍能看到未撤销的历史批次 |
| 已撤销过的批次 | 不重复撤销，可继续到更早的批次 |

## 验证记录

- `python -m unittest discover -s tests`：61 项通过；`python -m compileall -q fc2cmadb_crawler tools tests` 和 `git diff --check` 通过。
- FC2 目录工具在两个隔离根目录分别执行一批，重启后 `--undo 2` 依倒序恢复两个原名；BAT 菜单也完成一次改名和撤销。
- 快捷方式工具连续修改同一个 `.url` 两批，重启后 `--undo 2` 恢复；恢复后的字节与首批历史中保存的原始字节完全一致。BAT 菜单的撤销入口也完成实测。
- 视频工具在隔离 `LOCALAPPDATA` 中连续记录两批并撤销两批；又在两个独立进程间完成一次改名和撤销。旧 `last-operation.json` 入口用已恢复样例验证可读取并标记完成。
- 离线冲突用例验证：原目录名被占用或 `.url` 内容再次变化时，不执行恢复写入。
