# FC2 目录按制作人批次查询

## 目标与约束

- 一次根目录处理批次内，同一现有制作人字段首次出现时按名称搜索販売者；之后复用该次查询得到的最新制作人名称。
- 影片标题沿用原目录名，不再按每个番号查询新标题；合成的新目录名超出项目长度限制时直接按共享命名规则截断。
- 保留 `fc2-ppv-` 前与制作人前的文字，继续跳过边界不明、目标冲突或站点资料不可用的目录。
- 每个批次重建查询缓存；最短间隔按实际站点网址导航时刻计算，缓存命中和本地空白页不计入。429 重试逻辑保持现状。
- 测试和实际验收只预览，不改动用户目录。
