# 缩短重命名预览的差异标色

## 目标

- 视频文件、视频目录、FC2 目录的重命名与撤销预览，尽量只突出真正变化的文字；多处变化之间的相同文字保持普通颜色。
- Python 与 PowerShell 两套预览在常见名称长度下使用一致的最短差异规则，纯文本输出与实际改名行为不变。
- 过长路径避免明显卡顿；保留可辨认的预览。

## 样例与边界

| 输入 | 预期行为 |
|---|---|
| `A-old-middle-old-Z` → `A-new-middle-new-Z` | 两处差异分别标色，`middle` 不标色 |
| `movie.mp4` → `movie [023Mbps_2048p].mp4` | 只标色插入标签，旧名不标色 |
| 两个中文或日文名称 | 保留相同字符，突出最少的变更字符 |
| 源与目标相同 | 不标色 |
| 重定向输出 | 无颜色控制码，文字完整 |
| 视频和 FC2 工具的撤销预览 | 与正向预览采用相同的差异规则 |
