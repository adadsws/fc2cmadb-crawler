# 站点访问提示、販売者缓存与部分预览

## 目标与边界

- 用户补充：50 次改为单次 CMD/BAT 程序会话内的提示阈值。只统计实际导航到 `fc2cmadb.com/articles/...` 与 `/search` 的次数；达到 50 次时提示一次，继续访问，不限制功能。重新启动程序后从 0 计数，不持久化访问计数。
- 扫描目录时先统计现有販売者搜索名称的出现频率，优先处理高频组；执行重命名仍按目录深度排序，避免父目录先改导致子目录路径失效。
- 把已验证的販売者当前名、旧名及查询时间存于项目 `~outputs/`；30 天内命中当前名或旧名时复用资料，不访问站点。过期后重新查询。
- 工具首次收到 429 就停止本批后续站点获取。若此前已有可安全命名的目录，展示部分结果和未完成数量，由用户选择是否确认这一部分；不自动重命名。达到 50 次提示阈值不停止。
- 无缓存命中或站点资料不足时继续跳过，不猜测制作人边界。
