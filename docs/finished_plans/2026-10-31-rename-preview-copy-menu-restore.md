# 重命名预览、逐批撤销、复制菜单与测试目录还原

## 目标

- 用户再次补充：所有重命名与撤销入口改为先列出最近处理的文件夹路径，按编号选择要撤销的批次；不再输入 N。选择后才展示该批全部还原预览，确认后返回可撤销列表。
- 用户补充：预览完整性与逐批撤销规则适用于所有重命名操作及撤销操作，不限于视频重命名。
- 视频重命名预览按目录分组：先显示该目录的改名，再显示其下每个待改视频；所有实际待改名称均可见。
- 视频重命名与 FC2 文件夹更新均须预览所有待改目录；视频撤销预览也按目录及文件分组。
- 三种原地修改工具列出未撤销批次的处理文件夹；每次只预览选定批次的所有改动，确认后刷新列表。
- 非视频复制菜单调整为 1 复制到源目录旁、2 复制到默认目标路径；指定目标路径参数及手动输入仍可使用。
- 将 `V:\N\~q %db\q\test\t` 还原到目录更新工具改名前，保护原有内容与名称。

## 样例与边界

| 输入或状态 | 预期行为 | 预期输出 |
|---|---|---|
| 两个含多个视频的目录 | 每个目录先于本目录文件展示 | 目录 1、文件 1/2/3、目录 2、文件 1/2/3 |
| 某目录名称不变但文件需改 | 仍显示目录分组位置 | 仅列待改文件，避免误称目录会改 |
| 需要连续撤销 2 批 | 选择第一批并确认后刷新列表，再选择第二批 | 两次独立预览与确认 |
| 视频批次内含两个目录及文件 | 撤销预览按目录分组，列出全部待恢复路径 | 目录 1、所属文件、目录 2、所属文件 |
| FC2 文件夹更新批次含多目录 | 正向和撤销预览均完整列出所有目录 | 每个目录均有原名和目标名 |
| 快捷方式批次含多文件 | 每次仅显示所选批次，列出该批全部文件 | 逐批确认 |
| 已有三个未撤销批次 | 按最近处理顺序显示文件夹路径，回车选择首项 | 选中一批的完整预览，不要求输入批次数 |
| 旧版历史没有根路径字段 | 从记录中受影响的目录推导并显示 | 历史仍可选择和撤销 |
| 无可撤销批次 | 提示后返回主菜单 | 不进入空选择循环 |
| 复制模式回车 | 选第一个数字选项 | 源目录旁 `<源名>_nonvids` |
| 复制模式无法建立相邻目录 | 明确提示并保留默认输出方式 | 不写入源目录 |
| 测试目录原名证据不足 | 不猜测旧名 | 取得原名后核对并还原 |
