# 批量更新 FC2 作品文件夹名称

## 目标

- 新增可单独运行的目录维护工具，递归扫描用户指定的根目录，找出名称含 `fc2-ppv-<数字>` 的文件夹。
- 用主爬虫的 `fc2-ppv-{番号} {制作人}-{影片名}` 规则、非法字符清理和 80 字符截断生成新名称。
- 原名称中 `fc2-ppv-` 前的文字和番号与制作人之间的额外文字原样保留；文件夹内的文件不改动。
- 预览旧名与新名的差异，确认后才重命名；同名冲突或无法可靠解析时跳过，不覆盖已有目录。
- 工具可在当前模式连续输入下一个根目录；`b` 返回主菜单，`q` 退出。回车只在数字菜单选择第一项。

## 已确认的数据来源与保留边界

- 用户确认按 FC2 番号从 `fc2cmadb.com` 获取最新制作人与标题；只有原名称中的制作人及其后文字可修改。
- 测试编号 `4165309`、`3216009` 的详情页可通过 HTTPS 直接访问并读取 Inertia `props.article`。后者当前站点制作人是 `Dの計画`，旧目录中的 `KING POWER D` 需替换。
- 用户随后增加含空格的前置文字样例 `fc2-ppv-3899268_111 素人発掘隊！ 4610hakkutsu-...`，并再次明确：只有制作人及其后文字可修改。
- 优先用站点制作人名称或 slug 在旧名称中定位制作人起点；若不能匹配，才按旧名和父目录判断。边界不明时跳过，绝不猜测或改掉前置文字。
- 完整目录名仍遵循主程序的 80 字符上限；前置文字和制作人不截断，只缩短标题。若剩余空间连完整制作人与分隔符都放不下则跳过。

## 样例与边界

| 输入或状态 | 预期行为 | 预期输出 |
|---|---|---|
| `【TT】fc2-ppv-4165309 汁ハッピー☆-...` | 保留 `【TT】` 和制作人前空格 | 用主程序规则更新作品部分 |
| `fc2-ppv-3216009=111111111111111 KING POWER D-...` | 保留番号后的 `=111111111111111 ` | 用主程序规则更新作品部分 |
| `fc2-ppv-3899268_111 素人発掘隊！ 4610hakkutsu-...` | 保留 `_111 素人発掘隊！ ` | 将旧制作人及标题更新为站点值 |
| 名称含多个 `fc2-ppv-` 或缺少数字 | 不猜测目标 | 跳过并说明原因 |
| 目标名称已存在 | 不合并、不覆盖 | 跳过并列出冲突 |
| 根目录含嵌套匹配目录 | 从深层处理，避免父目录先改名导致子路径失效 | 逐项结果可核对 |
| 用户在预览输入 `b` 或 `q` | 不改名 | 返回主菜单或退出 |
| 再次扫描已更新目录 | 不重复改名 | 显示已符合新名称，退出码为 0 |
