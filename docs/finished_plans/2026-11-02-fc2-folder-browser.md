# FC2 目录更新工具复用项目 Chrome

## 目标

- `tools/run_update_fc2_folder_names.bat` 更新目录时，像主程序一样启动或复用可见 Chrome，并从同一浏览器会话读取最新作品资料。
- 保持先预览再确认、目录命名规则、批次撤销与模式内连续处理。
- `--undo` 只处理本地记录，不启动浏览器。
