# 程序菜单前准备运行环境

## 目标与范围

- 主爬虫与四个工具在显示交互选项前准备各自需要的运行环境。
- 主爬虫保留现有浏览器和登录准备顺序；FC2 文件夹工具交互入口先附加项目 Chrome，再显示模式菜单。
- 视频重命名工具先确认 FFprobe 可用，再显示模式菜单，并在本次运行中复用已找到的路径。
- 复制工具与快捷方式工具已有控制台初始化，维持其先于输入的顺序。
- 无交互菜单的 `--undo` 参数入口不启动浏览器；浏览器或 FFprobe 准备失败时明确报错，不显示无法执行的交互菜单。
