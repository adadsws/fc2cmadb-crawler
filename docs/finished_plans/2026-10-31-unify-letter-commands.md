# 统一 b 与 q 的命令含义

## 目标

- 主程序与三个独立工具的输入统一：`b` 返回主菜单，`q` 退出程序；字母大小写等价。
- 数字菜单保留首项回车默认；去掉与 `b` 返回、`q` 退出重复的 `0` 及英文单词别名。
- 输入流结束时安全退出，不因回车默认重复执行。

## 样例

| 场景 | 预期 |
|---|---|
| 主程序演员或 FC2 编号输入 `q` | 直接退出，不返回模式菜单 |
| 主程序编号输入 `b` | 返回模式菜单 |
| 复制工具目标选择或确认输入 `b` | 返回源路径主菜单 |
| 三个工具在各层输入 `q` | 退出，不执行尚未确认的操作 |
| 重命名工具预览输入 `b` | 返回主菜单，不改名 |
| 各菜单输入 `0` | 不再作为返回或退出快捷键 |
