# 统一三个独立工具的交互菜单

## 目标

- 三个工具在选定操作后可连续处理下一个输入，`b` 返回上一级，`q` 退出。
- 数字菜单回车选择第一个选项；路径和业务编号仍必须显式输入。
- 保持文件复制只读源目录、重命名预览与撤销、快捷方式修改确认等保护。
- 完成后用实际入口实测主程序和三个工具。

## 样例与验收

| 输入或状态 | 预期行为 |
|---|---|
| 复制工具选择相邻目标并完成一次 | 继续等待下一个源目录，保持相邻目标选项 |
| 快捷方式工具完成一次修复 | 继续等待下一个目录，保留目标域名 |
| 重命名工具完成一次改名 | 继续等待下一个目录；`b` 返回重命名/撤销菜单 |
| 任意数字选项输入空回车 | 选择该菜单第一个选项 |
| 路径输入空回车 | 不执行操作，提示重新输入 |
| 输入流 EOF | 安全退出，不重复执行默认选项 |

## 验证记录

- `python -m unittest discover -s tests`：39 个测试通过；`python -m compileall -q fc2cmadb_crawler tools tests` 通过。
- 主程序：`run_fc2cmadb_crawler.bat` 完成浏览器附加与登录准备后安全退出；`python -m fc2cmadb_crawler.main` 输入 `q` 正常退出，均未抓取任务。
- 复制工具：交互入口连续处理两个隔离源目录，保持相邻 `_nonvids` 目标方式，两个输出均存在。
- 快捷方式工具：交互入口连续修改两个隔离目录的 `.url`，确认菜单空回车选择 `1`，两个 URL 均改为目标域名。
- 重命名工具：交互入口连续展示两次预览并取消；另用短视频实际改名、返回菜单并撤销，文件与目录原路径恢复，退出码 0。
- 复制与快捷方式工具的 BAT 入口分别以 `q`、`0` 正常退出，退出码均为 0。
