# FC2 番号输入复盘

## 项目专项复盘

- 演员 ID 与 FC2 番号都是纯数字，使用数字键 `1`/`2` 区分模式，并保留直接多位数字作为演员 ID。
- FC2 详情只负责解析唯一演员 ID，后续继续复用原演员抓取流程，避免两套分页和输出逻辑分叉。
- Inertia 主作品数据优先于 DOM；DOM 回退仅扫描主内容的 `/actresses/{id}` 链接，并拒绝多演员猜测。

## 跨项目通用实践

- 新输入方式应转换为结构化任务对象，再由主流程分派，避免特殊状态散落在交互代码中。
- 从间接标识解析主实体时，零候选和多候选都应显式失败，只有唯一候选才能自动继续。
